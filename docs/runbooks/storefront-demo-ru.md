# Демонстрационная витрина v0.4

## Что это

Необязательное учебное наполнение: 24 товара, 48 вариантов, 6 категорий и 3 вымышленных магазина. Фотографии распространяются по указанным [лицензиям](../demo-image-credits.md); названия, цены и комплектации учебные. Отзывы, продажи, скидки и рейтинги не выдумываются. Деньги не списываются, доставка не заказывается.

Команда не включена в обычный запуск. Она создаёт только свои новые записи, не открывает старые карточки и не заменяет имеющиеся аккаунты. Повторный запуск ничего не меняет. Если служебный идентификатор уже занят посторонней записью, операция отказывается работать, а не перезаписывает её. Демонстрационные продавцы не имеют пригодных для входа паролей — это примеры витрин, а не готовые учётные записи.

## Добавить фотографии и товары

Сначала выполните обычную установку из [README](../../README.md): создайте `.env`, выполните миграции, подготовьте поиск и запустите приложение. Затем из того же каталога:

```bash
docker compose run --rm -e DEMO_CONTENT_ENABLED=true web python manage.py seed_demo_storefront --confirm-demo
```

Откройте [главную](http://127.0.0.1:8000/). Для просмотра вход не нужен. Флаг импорта действует только на этот запуск команды; не оставляйте его включённым постоянно.

## Корзина и тестовый заказ

В своей `.env` установите `DEMO_ORDERS_ENABLED=true`, сохраняя остальные ключи и настройки, и пересоздайте web/worker:

```bash
docker compose up -d --no-deps --force-recreate web worker
```

1. Зарегистрируйте собственный личный аккаунт и подтвердите почту письмом из локального Mailpit (`http://127.0.0.1:8025/`). Для публичных товаров отдельное приглашение в каталог не требуется.
2. Выберите товар и вариант, добавьте в корзину, измените количество или удалите ненужное.
3. Если цена изменилась, подтвердите новую цену обновлением строки. Цена и наличие повторно проверяются на сервере; скрытые значения формы не являются источником цены.
4. Оформите корзину. Либо создаются все строки заказа, либо ни одна. Повторная отправка возвращает тот же результат.
5. В учебном заказе можно имитировать одобрение/отказ оплаты и отмену. Реальная оплата, доставка и продажи отсутствуют. Полный сценарий передачи продавцом проверяется на собственных продавцах, а не входом в вымышленные магазины без паролей.

[Подробности модели демонстрационного заказа](demo-orders-ru.md).

## Обновление и возврат

Перед обновлением сохраните `.env`, базу и том фотографий по [инструкции резервного копирования](catalog-quickstart-ru.md). Примените обычные миграции: у существующих карточек `public_listing=false`. Публикация и разрешение гостевого просмотра — отдельные действия.

Для возврата используйте предыдущий исходный код/образ **вместе с** сохранённой базой, фотографиями и прежней `.env`. Не делайте обратные миграции наугад и не используйте `docker compose down -v`. Если откатываете данные, действия после резервной копии будут потеряны; сначала сохраните текущую копию.

Проект работает на том компьютере, где запущен Docker. `127.0.0.1` не является адресом сайта на телефоне и не публикует магазин в интернете.
