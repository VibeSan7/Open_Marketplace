# Open Marketplace v0.3.0 — catalogue usability and demo orders

[Русский](v0.3.0.md)

## Changes

- Home page with clear next actions and a built-in first-run guide.
- Russian account-security and seller forms; invalid seller applications preserve authorized submitted fields.
- Guided seller journey, readable listing states, publication readiness and private draft previews.
- Price ranges, sorting, condition-preserving links, personal saved products and seller pages.
- Separately enabled order demonstration: simulated approval/decline, handover, receipt and cancellation. Money and inventory effects are explicitly simulated. The existing catalogue stock tables are not changed.
- GitHub checks for changes, including browser tests and disposable database/photo restoration.

## Install and update

[README](../../README.en.md) · [First run](../runbooks/initial-setup-en.md) · [Order demonstration](../runbooks/demo-orders-en.md).

For a new installation generate a private `.env` as documented. For an upgrade keep your existing `.env` and back up the database and photos; **do not regenerate keys or delete Docker volumes**. Apply migrations before updating web/worker according to the runbook. Saved-product and demonstration tables are additive; existing listings remain intact.

`DEMO_ORDERS_ENABLED` is off by default. To try the demonstration in a test installation set `DEMO_ORDERS_ENABLED=true` in its `.env` and recreate web with `docker compose up -d --build web`. Never enter real personal or payment data.

## Release boundaries

This is an installable local project, not a deployed public store. Real payments, shipping, payouts, disputes and digital delivery are not implemented. The demonstration does not replace payment-provider selection or legal review. Closed admission and seller protections remain. No open-source licence has been selected; see [code-use status](../code-use-status.md).

v0.2.0 is preserved unchanged as the previous release.
