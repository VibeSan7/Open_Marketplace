# Open Marketplace v0.2.0: product catalog


Sellers create and publish products. Buyers search, select variants, and compare offers. The application runs on your computer through Docker and opens in a browser.

## Included

- Accounts, email verification, two-factor authentication, and staff roles.
- Separate catalog admission and seller approval.
- Drafts and publication, product variants, real photos, and private file serving.
- Prices in rubles, free offers, exact stock quantities in units, kilograms, and meters, and storage locations.
- Shared listings and offer comparison after a staff member confirms product identity.
- Keyword, typo-tolerant, and semantic search, filters, automatic loading of more results, and links to variants.
- Persistent storage, backups, and verified restoration of both the database and photos.

## Getting started

1. Download `Open-Marketplace-v0.2.0.zip` from the [release page](https://github.com/VibeSan7/Open_Marketplace/releases/tag/v0.2.0) and extract it.
2. Follow sections 1–4 of the [English README](../../README.md): prepare Docker, create settings, run migrations, download the search model, and start the application.
3. Open `http://127.0.0.1:8000/catalog/`.
4. Set up the administrator and the first product with the [English guide](../runbooks/catalog-quickstart-en.md).

Settings are created separately at first startup. The archive has no preset passwords or sample products. Local installation emails arrive in Mailpit at `http://127.0.0.1:8025/`, not in an external mailbox.

The English documentation was added after the original v0.2.0 archive was published. Use the online English guides with that archive, or clone `main` to get both languages. The original release archive and tag are unchanged. This documentation update does not change the application's interface language.

## Verification

The full suite of 503 tests passed, including real Chromium, PostgreSQL, and the local search model. Module boundaries, migrations, secure settings, a clean startup, and restoration of the database with photos were checked. The [validation report](../security/phase-2-local-validation.md) records the results and their limits.

## Not included

- A cart, orders, payments, or digital file delivery.
- A website deployed on the internet: this is a local installation, not a configured public server.
- Preconfigured personal accounts, shared passwords, or user data.

The repository was private when v0.2.0 was originally published; repository access was required at that time. Before updating an existing installation, back up the original `.env`, database, and photos. Do not use `docker compose down -v`: it deletes persistent data.
