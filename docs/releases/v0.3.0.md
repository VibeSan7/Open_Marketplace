# Open Marketplace v0.3.0 — удобный каталог и тестовый заказ

[English](v0.3.0.en.md)

## Изменения

- Главная страница с понятными действиями; инструкции первого запуска внутри сайта.
- Русские формы входа, защиты аккаунта и заявки продавца. Ошибки заявки не стирают разрешённые введённые данные.
- Путь продавца с подсказками, состояния карточек, проверка готовности и закрытый предпросмотр.
- Диапазон цены, сортировка, ссылки с сохранёнными условиями, личное избранное и страницы продавцов.
- Отдельно включаемый демонстрационный заказ: тестовое подтверждение/отказ оплаты, передача, получение и отмена. Все денежные и складские эффекты этой демонстрации условные. Реальные таблицы остатков каталога не изменяются.
- Автоматические проверки изменений на GitHub, включая браузер и восстановление тестовой базы/фотографий.

## Установка и обновление

[README](../../README.md) · [Первый запуск](../runbooks/initial-setup-ru.md) · [Демонстрация заказа](../runbooks/demo-orders-ru.md).

Для новой установки создайте собственный `.env` по README. При обновлении сохраните существующий `.env`, резервную копию базы и фотографий; **не создавайте ключи заново и не удаляйте хранилища Docker**. Запустите миграции перед обновлением web/worker по инструкции. Новые таблицы избранного и демонстрации добавляются без изменения прежних карточек.

`DEMO_ORDERS_ENABLED` выключен по умолчанию. Для испытания в своей тестовой установке установите `DEMO_ORDERS_ENABLED=true` в её `.env` и пересоздайте web через обычный `docker compose up -d --build web`. Не используйте настоящие персональные/платёжные данные.

## Границы выпуска

Это устанавливаемый локальный проект, а не запущенный публичный магазин. Настоящие платежи, доставка, выплаты, споры и цифровая выдача не реализованы. Демонстрация заказа не заменяет выбор платёжного партнёра и юридическую проверку. Закрытый допуск пользователей и защита продавцов сохранены. Свободная лицензия не назначена; см. [статус прав](../code-use-status.md).

v0.2.0 не заменяется и остаётся доступен как прежний выпуск.
